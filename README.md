# SiteGrab Pro

A powerful, modern website asset downloader. Input any public URL, and SiteGrab Pro will crawl the site, collect all frontend assets (HTML, CSS, JS, Images, Fonts, etc.), and package them into a clean ZIP file.

## ✨ Features

- **Deep Crawling**: Follow link levels to capture entire site structures.
- **Asset Filtering**: Choose exactly what you want to download.
- **Modern UI**: Clean, responsive interface with Lucide React icons.
- **Dark Mode**: High-contrast dark theme with persistent storage.
- **Offline Ready**: Heuristic scoring for how well the site will work offline.

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/krisvasoya/SiteGrab-Pro.git
   cd SiteGrab-Pro
   ```

2. Install dependencies for both parts:
   ```bash
   npm run setup
   ```

### Running Locally

You can start both the frontend and backend simultaneously from the root:

```bash
npm start
```

- **Frontend**: http://localhost:3000
- **Backend**: http://localhost:5000

## 🛠 Tech Stack

- **Frontend**: React, Framer Motion, Lucide React, Vanilla CSS
- **Backend**: Node.js, Express, Puppeteer, Archiver
- **Design**: Earthy Minimalist with Glassmorphism
